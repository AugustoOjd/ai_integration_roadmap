# Sources

**No LangChain Academy courses for this one.** Pydantic AI is a competing
ecosystem — everything you need is in its own documentation, which is good.

| Resource | Covers |
|---|---|
| [pydantic.dev/docs/ai](https://pydantic.dev/docs/ai/overview/) | Official docs. Agents, tools, dependencies, output types, message history |
| [Deferred Tools](https://pydantic.dev/docs/ai/tools-toolsets/deferred-tools/) | `requires_approval`, `DeferredToolRequests`, the full approval cycle |
| [pydantic.dev/llms.txt](https://pydantic.dev/llms.txt) | The docs in llms.txt format, for reading them with an agent |
| [Logfire](https://pydantic.dev/docs/logfire/) | OpenTelemetry-native instrumentation, Phase 5 |
