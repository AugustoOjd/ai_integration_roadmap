# Sources

⚠️ **LangChain Academy has no course on this.** No LCEL, no chains, no
retrievers, no RAG — post-1.0 their product is agents, and that catalog starts at
Project 5. The reference here is the docs, which are good for retrieval.

| Resource | Covers |
|---|---|
| [docs.langchain.com/oss/python](https://docs.langchain.com/oss/python/langchain/overview) | Official docs. The **retrieval** section is the one for this project |
| [LCEL / Runnable](https://docs.langchain.com/oss/python/langchain/runnables) | The `\|`, `RunnableSequence`, `RunnableParallel`, `RunnablePassthrough` |
| [PGVector](https://docs.langchain.com/oss/python/integrations/vectorstores/pgvector) | The vector store, and the psycopg3 warning |
| [Voyage AI embeddings](https://docs.voyageai.com/docs/embeddings) | The hosted model, `output_dimension`, free-tier limits |
| [Quickstart: LangSmith Essentials](https://academy.langchain.com/courses/quickstart-langsmith-essentials) | **Academy, ~1 h.** Observability — seeing the steps a chain hides. Relevant to Phase 3 |
