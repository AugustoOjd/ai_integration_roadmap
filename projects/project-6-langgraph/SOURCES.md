# Sources

| Resource | Covers |
|---|---|
| [LangGraph docs](https://docs.langchain.com/oss/python/langgraph/overview) | `StateGraph`, checkpointers, `interrupt`, streaming |
| [Persistence](https://docs.langchain.com/oss/python/langgraph/persistence) | Threads, checkpoints, the saver's data model |
| [Quickstart: LangGraph Essentials - Python](https://academy.langchain.com/courses/langgraph-essentials-python) | **Academy, short.** State, Nodes, Edges, Memory |
| [Foundation: Introduction to LangGraph - Python](https://academy.langchain.com/courses/intro-to-langgraph) | **Academy, 55 lessons · ~6 h.** Introduction · State and Memory · UX and HITL (streaming, breakpoints, time travel) · Building Your Assistant (parallelization, subgraphs, map-reduce) · Long-Term Memory (Store) · Deployment |
| [Project: Ambient Agents with LangGraph](https://academy.langchain.com/courses/ambient-agents) | **Academy.** Guided project: an email assistant from scratch |
| [github.com/langchain-ai/langchain-academy](https://github.com/langchain-ai/langchain-academy) | The course notebooks |

The Foundation is the heaviest course in the catalog. Its modules 4 (subgraphs,
map-reduce) and 5 (long-term memory, the Store) are the ones you won't discover
on your own.
