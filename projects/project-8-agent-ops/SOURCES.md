# Sources

This is the full LangSmith track. It's the one fewest people do, and the closest
to actual production work.

| Resource | Covers |
|---|---|
| [Foundation: Introduction to Agent Observability & Evaluations](https://academy.langchain.com/courses/intro-to-langsmith) | **Academy.** The base: traces, datasets, evaluators, experiments |
| [Foundation: Building Reliable Agents](https://academy.langchain.com/courses/building-reliable-agents) | **Academy.** From "it runs" to production, through iteration cycles |
| [Foundation: Monitoring Production Agents](https://academy.langchain.com/courses/production-monitoring) | **Academy.** Cost, trends, trace analysis, quality and latency |
| [Foundation: Introduction to LangSmith Deployment](https://academy.langchain.com/courses/langsmith-deployment) | **Academy.** Deploying and managing agents |
| [Quickstart: Autonomous Agent Improvement with LangSmith Engine](https://academy.langchain.com/courses/langsmith-engine) | **Academy.** The full cycle: trace error → proposed fix → experiment → monitor regression |
| [docs.langchain.com/langsmith](https://docs.langchain.com/langsmith/home) | LangSmith docs |
| [openevals](https://github.com/langchain-ai/openevals) | Pre-written evaluators |
